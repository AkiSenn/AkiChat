# AkiChat UI/UX 融合需求与阶段验收

融合“用户体验重构与五项核心功能修复”附件及“正式执行 UI/UX 优化计划”。两份要求同时保留；按正文明确的 A → B → C → D 顺序执行，先完成 A 的测试 IPA，再推进后续阶段。各阶段独立提交、PR 和 CI；不自动合并，不发布正式 Release，不更改 1.2.0 版本线、Bundle ID 或数据格式。

## 审查结论

基线 main `c1cb8d8`，2026-10-25 查询 GitHub 当前无未合并 PR。已检查 ProvidersView、ModelsView、ModelSelectionPanel、ChatView、ChatComposer、ReasoningControls、AdvancedConversationView、SettingsView、ModelDiscovery、ContextManager、AppStore、RequestBuilder、Tools、ChatRun、AdvancedModels。

- 已有自动发现、离线目录、手动模型、收藏和跨服务商真实请求切换，保留该路径，不新增第二套网络或模型状态。
- 添加页面同时要求服务商与单模型信息；Store 要求显示名称非空，阻碍无模型配置保存。保存后立刻关闭编辑器，异步发现结果没有连续的选择步骤。欢迎页绕到全局设置。
- 思考在输入栏、控制台和全局设置存在三个入口；输入栏有直接切换与跳控制台两种行为。搜索直接轮换模式，授权和来源另在控制台。
- ContextManager 已保护原始轮次和工具链；控制台暴露过多参数。摘要仍可使用独立配置。保留这些底层机制，在后续阶段调整入口和解析规则。

## A：API 添加与模型发现（本 PR）

- 默认三项输入及保存并获取模型；协议、路径、Header、超时、局域网授权、旧默认值和能力覆盖折叠保留。
- 复用异步发现、后台目录解析/合并、取消与陈旧响应保护。保存后显示进度和模型列表，用户明确选择默认模型及当前会话模型。
- 404/405 显示兼容模式；401、403、429、非法 JSON、超时分别提示；不据此断言聊天接口无效。任何失败不清空目录，手动与远端模型共存。
- 欢迎页直达 API 服务商；顶部仍按真实服务商/模型切换，保持搜索、收藏和手动管理。
- 不改持久化类型或新增必需字段；保留原路径、Keychain 引用、会话选择、覆盖值、摘要版本及历史。新通用配置使用规范化的 /v1 路径。
- 自动测试：无模型保存后自动 GET、默认模型/真实请求/密钥、重启读取、失败保留及手动模式、分类错误、路径规范化、无效保存无副作用；UI 验证欢迎页直达与三项表单。实际 GitHub macOS 编译与 IPA 验证结果记录于 PR。
- 真机待验收：XR/iOS 14.8、iOS 16，真实服务商目录与 Key，保存→选择→连续聊天，手动兼容模式、键盘与深色布局。

## B：思考与联网独立面板（待实施）

- iOS 14 自定义底部面板，点击关闭/取消；关闭灰色但可点击，开启强调色，不能关闭明确说明。
- 读取缓存元数据；必要时仅异步刷新当前服务商。推理档位来自声明，未知仅“默认（由模型决定）”；能力未知可经高级覆盖。保留 DeepSeek、Hub 及其他协议的独立参数适配。
- 删除全局/控制台重复思考入口，保持唯一会话状态及真实请求。
- 联网面板集中关闭/自动/每次、来源与授权；没有来源时明确添加入口。工具开关保留高级入口，不复制联网状态。

## C：聊天记忆及当前模型自动整理（待实施）

- 普通界面“聊天记忆：自动管理（推荐）”，高级参数折叠。区分输入、总窗口和输出容量；元数据优先，未知保守并明确提示。
- 手动上限 300K/600K/1M/自定义只是客户端尝试上限；遵守已知真实容量，超限提示降低上限，不无限重试。
- “保留最近对话：8 轮”及一问一答解释置于高级项，保留现有轮次计算和原文保护。
- “自动整理旧聊天”及额外调用费用说明；实际使用当前解析后的 Provider/Model/Key，不只是隐藏摘要 Picker。兼容读取旧独立摘要字段；保留摘要原模型、时间、usage、回滚、失败保护和防重复覆盖。

## D：搜索来源（待实施）

- 复用 SearchProviderService，保留 DeepSeek Search/Fetch；增加自建 SearXNG JSON 和 Brave Keychain 适配；Brave 认证/额度/费用据官方资料核实，不声称无限免费。
- Bing 仅可选实验性自建服务，如 OpenSERP；不使用退役官方接口，不绕过访问限制。
- 自动搜索需真实工具能力；无工具模型的“每次搜索”可客户端先搜索再注入外部参考，不能伪造模型工具调用。
- 真实 URL/引用、外部数据隔离、取消/超时/错误处理、明确费用与隐私授权。Mock 验证来源响应及失败，不使用真实用户密钥。
