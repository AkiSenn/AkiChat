# 后续增强（不冒充已完成）

- Bing HTML 搜索实验模式：未实现，没有入口按钮；核心搜索完全使用 DeepSeek 官方 Search / Fetch。若开发，先评估网站条款，遵守验证码/反爬限制，独立编写解析器，失败时提供明确错误与官方搜索回退，不复制 Chatbox GPL 代码。
- Tavily / BoCha：`SearchProviderService` 已定义可取消 search/fetch 协议，尚无这两种实现或配置按钮。
- MCP：工具执行抽象 `ToolExecuting` 可扩展，当前没有 MCP 服务器连接或任意工具加载。
- 高级统计：已有逐消息 usage、请求预算估算与校准、摘要额外 usage、工具/搜索调用次数；未来增加跨会话趋势、价格账单与可导出统计图，不把估算当成精确计费。
- 更多主题：已有浅色、深色、跟随系统、原生毛玻璃；后续可增加强调色和更细的排版预设。
- CommonMark 完整一致性、复杂数学公式、代码语法高亮、图片生成、云同步：未实现。
- Assistant Prefix Beta 目前仅 DeepSeek、与工具互斥；其他兼容接口需先验证协议再适配。

任何扩展必须保持 iOS 14.0 / arm64 真机工作流和完整历史不丢失；不通过提高系统要求或静默移除主要功能修复 CI。
